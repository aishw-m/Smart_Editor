Deployment path (full details in README.md → Deployment):

  1. Push this repo to GitHub.
  2. Create a free Turso database at https://turso.tech and copy the
     database URL and auth token.
  3. Import the repo into Vercel and set these environment variables on
     the project (Settings → Environment Variables):
        DATABASE_URL          libsql://your-db.turso.io
        DATABASE_AUTH_TOKEN   <your turso token>
        SESSION_SECRET        <random 32-byte hex string>
                              (generate with: openssl rand -hex 32)
  4. Deploy. Once Vercel reports "Ready", replace this entire file with
     just the live URL on a single line, e.g.

        https://collab-docs-yourname.vercel.app

  Anyone with that URL can sign in by entering an email — no password
  required for this demo. Sharing works across two different emails.
